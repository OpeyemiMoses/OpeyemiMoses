## Coding Principles

* **Build Before Perfecting:** Ship functional MVPs first, then iterate aggressively based on empirical usage data.
* **Simplicity Scales:** Keep component trees modular, dependencies lean, and interfaces clean.
* **Automate Repetitive Work:** If a task needs to be done twice, write a script or delegate it to an agent.
* **Documentation Matters:** Write clear READMEs, API specs, and inline docstrings so anyone can jump in.
* **Security & Privacy First:** Never hold custodial funds, isolate private keys, and enforce hardware device integrity.
* **Ship Consistently:** Small daily commits beat infrequent massive refactors.
